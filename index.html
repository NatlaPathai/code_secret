Quatre couleurs. Dix chances de percer le secret.

Observez les indices, ajustez vos choix et retrouvez le code caché. Une même couleur peut apparaître plusieurs fois.

Les règles du jeu

Quatre couleurs à retrouver en dix essais

Le code contient 4 couleurs parmi 6, avec répétitions autorisées. Retrouvez les couleurs dans le bon ordre.

Bien placée

Bonne couleur, bonne position.

Mal placée

Couleur présente, à une autre position.

Toutes les règles et un exemple

Les indices donnent deux nombres, sans désigner les positions. Chaque pion compte une seule fois : les bien placés d’abord, puis les mal placés. Une proposition refusée ne consomme aucun essai. Quatre couleurs bien placées donnent la victoire, même au dixième essai. Après dix essais sans victoire, la partie est perdue. Le code reste caché. « Nouvelle partie » remet les essais et les choix à zéro.

    Exemple : pour le code rouge–rouge–bleu–vert, proposer quatre rouges donne 2 bien placées et 0 mal placée. Les deux rouges supplémentaires ne comptent pas.
