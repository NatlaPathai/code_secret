    Les règles du jeu

    Chaque indice compte.

    Le programme choisit un code fixe de 4 couleurs parmi 6. Vous avez 10 essais pour retrouver les couleurs et leur ordre.

    Bien placée

    La bonne couleur à la bonne position.

    Mal placée

    Une couleur du code, à une autre position.

    Les indices donnent des nombres, pas les positions. Chaque pion compte une seule fois : les bien placés d’abord, puis les mal placés.

    Les six couleurs

      Un exemple avec des répétitions

      Pour un code rouge, rouge, bleu, vert, une proposition de quatre rouges donne 2 bien placées et 0 mal placée. Les rouges supplémentaires ne comptent pas.

      Modifiez librement vos quatre choix avant de valider. Une proposition refusée ne consomme aucun essai. Après la fin, lancez une nouvelle partie.
